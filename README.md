# Tópicos Importantes para Avaliação

- O que é Framework?
Estrutura pronta que fornece ferramentas e regras para facilitar o desenvolvimento de aplicações.

- Qual a diferença dentre bíblioteca e framework?
A biblioteca é usada quando o desenvolvedor a chama para executar funções específicas. Já o framework controla o fluxo da aplicação e define a estrutura do projeto.

- O que é Javascript?
Linguagem de programação usada para criar páginas e aplicações web interativas.

- O que é Node.js?
Ambiente de execução que permite rodar JavaScript fora do navegador, como em servidores. (run time).

- O que é o NPM?
"Gerenciador de pacote do node" permite instalar, desinstalar, rodar scripts, atualizar (npm = instala e npx= executa).

- O que é biblioteca React?
Biblioteca JavaScript criada para desenvolver interfaces de usuário de forma rápida e organizada. 

- O que é biblioteca React Native?
Permite criar aplicativos para Android e iOS usando JavaScript.

- O que é a framework Expo?
Framework que facilita o desenvolvimento, teste e publicação de aplicativos feitos com React Native. (além da biblioteca um ecossistema para facilitar).

- O StyleSheet do React Native tem todas as propriedades da Web?
Não

- Todos as propriedades do StyleSheet funcionam para iOs e Android?
Não, mas a grande maioria funciona porém tendo algumas exceções. 

- Quais as principais formas de navegação com Expo Router?
-Stack - empilhamento (uma tela em cima da outra).
-Tabs - barra de navegção em baixo.
-Drawer - menu "hamburguer" (lateral).
-Modal - mensagem no meio tela (tipo uma mensagem) - continua sendo um stack.
